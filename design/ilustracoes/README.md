# Ilustrações

Fontes SVG das imagens em `conteudo/imagens/`. Cada arquivo tem 800×500 e usa as
cores do app (`src/tema.ts`) e a fonte Inter.

Para gerar o PNG usado no app, renderize o SVG em 1,5× (1200×750) — por exemplo,
abrindo no navegador e capturando, ou com Playwright — e salve em
`conteudo/imagens/<id-do-guia>/<mesmo-nome>.png`.

| SVG | Usado em |
| --- | --- |
| `aperto-em-cruz.svg` | Trocar pneu furado, passo 5 |
| `pontos-da-gema.svg` | Cozinhar ovo, passo 3 |
| `teste-do-dedo.svg` | Regar plantas em vaso, passo 1 |
| `onde-ver-a-pressao.svg` | Calibrar pneus, passo 1 |
